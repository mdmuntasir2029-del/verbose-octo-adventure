Host Free Online

This application is a 100% static single-file web app. You can host it online for free in less than 2 minutes:

Option 1: Netlify Drop (Easiest - 30 seconds)

  1. Click "Save HTML Web App File" in the sidebar.
  2. Go to app.netlify.com/drop in your browser.
  3. Drag and drop the saved HTML file into the upload box.
  4. Netlify will give you a live HTTPS link to send your friend!

Option 2: GitHub Pages

  1. Create a free GitHub repository.
  2. Upload this index.html file.
  3. Enable GitHub Pages under Settings -> Pages.
